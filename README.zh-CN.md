# DSH Remote

一个独立的新项目：Bun 中继后端、真实 DSH/Cordis 受控插件、Bun 出站连接器、TanStack Web 控制台，以及 Flutter Android/iOS 客户端源码。

当前交付是可继续运行、测试和发布的源码快照，**还没有达到「完整真实端到端验收完成」**。详细证据与阻塞见 [验证记录](docs/verification.md)；不得把模型脚本测试或 DOM 测试当作真实模型、实际浏览器或手机实机验收。

## UI/UX 设计要求

[可点击原型](docs/prototype/README.md) 已基于 DeepSeek Harness 原生样式完成，54项本地检查和24项实际 Chromium 走查通过，并检查了桌面/移动、明/暗模式的代表性截图。它仍是明确标注的模拟原型。真实 Web 和 Flutter 客户端已完成样式与交互落地，并通过各自的本地真实 DSH / DOM 或组件检查；这一新版的托管浏览器和 APK 验证仍是独立关卡，不能把原型通过视为应用完整验收通过。

## 已实现

- 多用户隔离，每位用户拥有多个 DSH 实例和控制端
- 每个受控实例同时只有一个写入控制端；其他端可查看，可显式接管
- 控制权租约、过期处理、主机确认后生效的接管和旧指令隔离
- 真实会话创建、列表、历史与分页、实时流、发送、steer、取消及显式恢复
- 队列编辑/优先执行/删除，模型选择，带版本校验的许可/Agent 预设调整
- 文件和图片传入、图片读取，绑定具体会话及主机启动代次的一次性审批
- 断线事件恢复、命令幂等标识、未知结果提示、设备撤销与连接凭据轮换
- Web 使用 HttpOnly Cookie；移动端接入操作系统安全存储

DSH 仍在官方支持的 Node 主机中运行。只有中继后端和插件管理的出站连接器使用 Bun，不假设 DSH 原生支持 Bun。

## 本地启动

需要 Bun 1.4.2、Node 24；移动端需要 Flutter 3.47.6。使用官方工具分发源。

```sh
bun install --frozen-lockfile
bun run check
bun run test:web
bun run test:web:integration
REGISTRATION=enabled bun run dev
```

打开 http://127.0.0.1:3000 。注册默认关闭；上面的环境变量仅显式打开本地账户初始化。完成所需账户创建后，重启并移除该变量。不要直接把开发监听端口暴露到公网。

在 DSH 的「插件」页安装 DSH Remote 插件；在控制台新建实例后复制一次性配对链接，粘贴到 DSH 中该插件的页面即可连接，并在同一页面选择允许远程访问的工作目录。凭据保存在 DSH 凭据库中，无需命令行或令牌文件。无界面（手动配置）方式见 [插件说明](packages/dsh-plugin/README.md)。

模型供应商的密钥留在 DSH 主机本地，不交给中继服务。`allowedWorkspaceRoots` 必须列出允许远程查看与操作的已有工作目录，远端不能扩大范围。

## Cloudflare 部署

同一套中继核心也可运行在 Cloudflare Workers 上：Worker 托管 Web 控制台，单个 SQLite Durable Object 保存中继状态并持有全部 WebSocket；注册可要求邀请码。步骤与免费额度限制见 [Cloudflare 部署说明](docs/deploy-cloudflare.md)。

## 重要语义

`steer` 在下一个步骤边界优先处理，不会直接打断正在执行的模型请求或工具。查看冷会话不会自动启动任务；恢复执行需要当前写入控制权。

命令被接收，不等于模型回合已完成。出现 `indeterminate` 表示实际结果未知，应先查看 DSH 真实状态，不能换一个新 ID 盲目重发。

上游 `model.select` 还会异步更新 DSH 默认模型；界面有提示。可远程调整的是明确允许的会话参数，不包含任意凭据、插件安装、原始配置或安全策略修改。

源码、SDK、运行数据库和密钥严格分开；源码包不含 SDK、副本仓库、数据库或真实凭据。

## 新增后端能力

实例查询已区分连接中、在线、观测过期和离线，并返回最后观测时间。GitHub 使用部署方配置的只读 GitHub App；仓库授权、现有本地路径绑定、主机校验和消息引用是不同状态。主机在每次发送前重新校验仓库，仅注入名称、路径、分支、提交和链接等元数据，不传凭据或仓库文件内容。当前没有自动克隆，原生端需先通过同账户 Web 完成 GitHub 连接。两个客户端已接入这些接口，新版托管验收结果需另行核对，详见[接口与授权边界](docs/github-repositories.md)。
